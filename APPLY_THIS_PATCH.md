# Cách áp dụng patch

1. Giải nén file ZIP.
2. Copy toàn bộ nội dung bên trong vào gốc repo `tieng-trung-web`.
3. Chọn **Replace / Ghi đè** khi Windows hỏi.
4. Không copy nguyên thư mục patch thành một thư mục con.
5. Patch này không yêu cầu xóa thêm file.
6. Chạy local server và thực hiện list test trong `reports/UI_HEADER_BREADCRUMB_20260717.md`.
