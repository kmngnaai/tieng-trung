# Chinese serif font rollout V1

- Chinese characters, vocabulary, examples, radicals and flashcard prompts use the serif stack from Listening.
- Vietnamese UI, pinyin, numbers and controls remain sans-serif.
- Existing module layout CSS is not rewritten; one late-loaded shared override file applies the font safely.
- Radical 50 wraps only CJK runs inside mixed Markdown content.

See `FONT_TEST_REPORT.md` for local verification.
