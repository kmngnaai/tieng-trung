# New HSK Course — prototype dữ liệu

Prototype này chứng minh một bài học có thể phục vụ đồng thời hai cách xem mà không nhân đôi nội dung:

- `views.bookFlow`: đúng trình tự sách.
- `views.groupedIndex`: gom theo từ vựng, hội thoại, ghi chú, bài luyện, bài đọc và mở rộng.

Dữ liệu runtime hiện chỉ có HSK 1 Bài 1. Xem hướng dẫn ở `../../APPLY_NEW_HSK_COURSE_PROTOTYPE.md`.
